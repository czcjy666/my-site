# my-site

「工业运维 AI Agent 工作台」的项目展示页。纯静态：HTML + CSS + JS，无构建步骤、无外部请求、无依赖。

- `index.html` — 页面与全部文案
- `styles.css` — 样式（设计变量都在 `:root` 里）
- `main.js` — 截图缺失降级、导航描边、占位链接
- `assets/` — favicon 与截图目录

## 本地预览

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

直接双击 `index.html` 也能看。

## 设计口径

白底、黑字、灰底纹、发丝分割线；全局只有一个强调色（`--acc`，蓝色，只用在区块编号和焦点态）；不渐变、不光晕、不噪点、不玻璃拟态、不加阴影、不做装饰性动效。中文字体走系统栈（PingFang SC / 微软雅黑），不做负字距。

改风格只需动 `styles.css` 的 `:root`：`--acc` 换强调色，`--line` 换分割线深浅，`--t1/--t2/--t3` 换文字层级。

## 部署

仓库 Settings → Pages → Source 选 `main` 分支 / root 目录，即可通过 GitHub Pages 访问。

## 注意

页面里的数字与字段均来自项目本机/测试环境实测，展示中的设备、台账号与单据为演示数据；放截图前确认演示公司名（华明精密制造）不是真实客户或雇主名称。
